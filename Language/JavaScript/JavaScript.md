# Spec & Version Compatibility

- [ECMA-262 语言规范](https://www.ecma-international.org/publications-and-standards/standards/ecma-262/)

每年都会发布一个新版本的规范。最新的规范草案请见 https://tc39.es/ecma262/

- [ECMAScript 版本兼容性表](http://kangax.github.io/compat-table/es6/)

一份列有语言功能以及引擎是否支持这些功能的表格（可查看用户当前浏览器、使用的 js 编译器如 node 的支持功能）

- [查看浏览器可用的功能](https://caniuse.com/) 每个功能的支持表（现代网络技术的浏览器支持表）
- [ECMAScript 标准所有各阶段的提案](https://www.proposals.es/)
