# 降低读者负担

读者负担是读者为了理解代码必须做的工作。它有两根彼此独立的轴：问题和答案之间要追的层数，以及读者必须记在脑子里的隐藏或可变状态。两根都要守。

- 折掉只做转发的层：只有一个调用方的包装、没有第二份实现的适配器、直通方法。把它们内联。
- 缩小状态范围：返回优于改写，局部优于字段，字段优于模块状态，模块状态优于全局。派生，不要同步。
- 不变量在边界点名一次，不要在每个消费者里点名。

检验：一个新读者能不能在 30 秒内回答「X 从哪来？」和「什么能改 X？」不能的话，砍层或砍状态。
