# 造杠杆

工作不平凡时，造一个做这件事的工具（codemod、脚本、生成器，或一个可重跑的检查），不要用手做。门槛是平不平凡，不是重不重复。只有两三处显然的改动，才跳过工具。

- 先用手做第一个单元，再造工具，并把它在那个单元上重跑，以此证明它。让它重跑是安全的。
- 确定的工具胜过扇出。真要扇出时，把配方、验证契约和围栏写成一份受托方会读、却不能编辑的 skill。
- 应用这一条会产生一个文件。diff 里没有脚本、codemod、生成器或受托 skill，就说明你没有应用它。工作活过这次会话时，把它 commit 进去。
- 造能做完或证明这件事的最小脚本，绝不要造一个框架。
