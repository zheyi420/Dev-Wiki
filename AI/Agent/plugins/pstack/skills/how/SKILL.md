# How

探索代码库，回答「X 是怎么工作的？」。

范围含糊时，说出你的理解再探索。用户可以改方向。

## 1. 解释

拉起一个带 `subagent_type: generalPurpose` 和 `readonly: true` 的 Task subagent，一次走完探索和解释。把用户的问题和这份简报给它：

> 你在给一位资深工程师写架构说明。探索代码库，写出一份说明，让一位不熟悉这块的资深工程师读完就能带走一个扎实的心智模型。他们应当把架构理解到可以有信心开始在里面干活。你对代码库只有只读权限。

## 2. 呈现

呈现 subagent 的输出。为了清楚，或为了补上对话里的上下文，做轻量编辑可以。不要实质性地重写它。
