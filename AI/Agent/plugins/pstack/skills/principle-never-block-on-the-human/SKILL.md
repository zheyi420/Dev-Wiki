# 不要堵在人身上

人是异步监督的。agent 必须保持不被堵住。做出合理决定，继续往下做，让人在事后纠正方向。代码改动可以回退、可以评审，一个错误决定的代价通常小于停下来等。

- 先做，再摆出来。把活做完，展示结果。不要问「我该做 X 吗」。做 X，并说明为什么。
- 让系统能自己愈合。注意到问题时，记下来，下一轮修掉。
- 不可逆的动作（force-push、删除生产数据、对外发消息）仍然要确认。
- 可逆的动作（写代码、改笔记、拆任务）应当继续，不要堵住。
- 产品方向来自人。执行不应当堵住。
