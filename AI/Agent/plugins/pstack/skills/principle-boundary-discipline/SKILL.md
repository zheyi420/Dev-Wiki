# 边界纪律

在数据跨过系统边界的地方（CLI 参数、配置文件、外部 API、网络）做校验、收窄类型、处理错误。在内部，信任类型：不再重新校验，也不做多余的空值检查。在边界把原始数据解析成领域类型，不让传输和框架类型出现在公共表面上。业务逻辑活在没有框架依赖的纯函数里。调用它们的外壳是薄的。

两个检验。这份数据此刻是不是正在跨过边界？如果不是，校验就是多余的。这能不能做成一个纯函数，让外壳只是调用它？如果能，就抽出来。
