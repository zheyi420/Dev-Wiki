# 基础性思维

写逻辑之前先把数据形状定对。早点定义核心类型，追每一条访问路径，选择匹配主路径的结构。对结构做 DRY，不是对每一行。

在参与者之间共享状态之前，问如果另一个参与者同时改它会怎样。如果答案不是「没事」，就隔离。

先搭脚手架。对后面每个阶段都有帮助的东西（CI、测试、共享类型）先做，在删掉死代码之后。commit 保持小，并且只做一件事。
