# 证明它能工作

直接检查真实的东西，验证每一项产出：运行这个功能，读实际的值，查看 diff。替身（文件修改时间、自我报告、缓存的输出、「它能编译」）不算。检查失败时，先怀疑观察方法，再怀疑系统。

能写成脚本就写成脚本。一个能重跑这项比较的确定脚本，胜过看一次。把它的输出放在人看得见的地方，只有事后必须能审计这条痕迹时才 commit。
