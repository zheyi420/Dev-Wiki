### 视觉对齐

**像素级等价归你。基线就是规格。你不要碰它。** 等价靠图像 diff 来验证，不靠眼睛。

1. 任何迁移之前，先立好基线：一套视觉回归 harness，把当前组件在各个状态下截图；要对齐两套实现时，把目标也放进去。没有基线，就不要声称对齐。这是挡住后面的前提，不是后续再补。
2. 反抄近路的条款，写明并且守住：不改 harness，不篡改基线，不为了让 diff 通过而去重组组件。基线看起来不对，就停下来问，不要改它。
3. 一次迁移一个组件。跨 worktree 并行，一个组件一个负责人（**separate-before-serializing-shared-state** 原则 skill）。共享原语作为会挡住后面的阶段，先行迁移。
4. 每个组件都通过控制 skill，在对应的使用面上，用图像 diff 对照它的基线。非零的 diff 就是失败。去查像素差值。每个组件都 `/loop`，直到 diff 为零。
5. 按组件，或按安全的一批，跑 **开 PR**。

**回复：** 迁移了哪些组件、每个的 diff 结果、基线 harness 的位置、还剩下什么。
