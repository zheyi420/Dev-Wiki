### 安全暂停

**干净地停下来归你。留下一份检查点，让冷启动的 agent 能从这里接着干。** 只有明确要求时才走这里。对方说「继续」「我去睡了，继续」或「别停」时，不要暂停。

1. 停在安全边界上。把当前的原子步骤做完，或者从里面退出来。不要开始新的，并取消所有嵌套的 subagent。
2. 不要为了暂停采取不可逆动作。不要开 PR，也不要推送，除非你本来就已经发出去了。
3. 让工作留得住。把未 commit 的修改收成当前分支上一个清楚的 `wip:` commit，这样什么都不会丢。工作树是坏的，就在 commit 正文里用一行说明。
4. 把续作笔记写到上下文之外。记下意图、你正在做的事、进度以及已经验证的部分、当前状态、下一步、关键文件和易踩的坑。如果触发的是上下文压缩，写到类似 `/tmp/<slug>-resume.md` 的文件里。已经有 show-me-your-work 的轨迹，就指向它，不要再复制一份。

**回复：** 你在循环的哪一步、哪些在磁盘上、哪些还在你脑子里（给路径，不要把 diff 倒出来）、你做了哪些 commit、工作树是否干净，以及恢复后的第一个动作。这是一次暂停，不是结案报告。
