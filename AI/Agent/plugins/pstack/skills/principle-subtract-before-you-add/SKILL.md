# 先减再加

让系统演进时，先去掉复杂度，再建造。默认做减法。

把简化当成持续的投入。离开时，设计应当比你进来时稍简单一点、能力稍强一点，公共表面相同或更小。

- 先移除，再建造
- 打磨之前先砍（先到达最小，再投资质量）
- 按观察到的用法设计，而不是按臆测的边界情况
- 不要加规格没有要求的臆测校验器、解析器或守卫
- 简化 prompt（去掉重复的指示和过度的模板）
- 一处引用没有新内容时，删掉它，不要留一个占位
