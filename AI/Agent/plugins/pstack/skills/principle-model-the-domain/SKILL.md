# 为领域建模

把领域编码进数据结构，不要散落在条件分支里。对的结构会让非法状态无法表示，并删掉分支。

可以选用：状态机，而不是散落的布尔值或阶段检查；带类型的模型，而不是松散的参数；映射、注册表或可区分联合，而不是摊在多个文件里的分支；reducer，而不是临时的状态变更；以及访问模式需要时，用索引、队列或规范化集合。

不要硬套。形状清楚、局部、不太会长大时，留着平淡的代码。对只增加间接层、却没有去掉分支或非法状态的抽象保持怀疑。

你跳过了这一步的迹象：一个功能又给 if/else 链加了一条分支，或者又多了一个必须和第一个保持同步的布尔值。
