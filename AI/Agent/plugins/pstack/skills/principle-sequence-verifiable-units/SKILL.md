# 把工作排成可验证的单元

把工作排成小单元，每个单元结束于一个你能检查的状态，当前这个没变绿就不要前进。

在一次扫荡、一次迁移，或一串相似的编辑里，每个单元是一个括号：已知良好的状态，一次改动，跑检查，继续。即使是工具在做这些编辑，每个单元的检查也要跑。

按能证明这项工作的顺序交付：失败的测试在前，然后是修复。重塑之前先做减法。处理之前先抓基线。每个 commit 自己能落地。
