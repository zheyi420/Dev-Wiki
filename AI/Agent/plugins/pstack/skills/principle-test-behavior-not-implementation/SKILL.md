# 测行为，不测实现

测试是一个声明，声明的是代码的用户通过它的界面能观察到什么：返回值、错误、他们能读回来的状态，以及对外部系统的影响。私有辅助函数、内部调用顺序和中间数据是实现。

用两种想象中的编辑来评判每个测试：

- **打破行为**（错误的值、被跳过或做了两次的效果）。如果测试仍然通过，它什么也没证明。常见原因是：断言太松、期望值由被测代码算出来，以及对测试自己造出来的数据做断言。
- **改内部实现**，并保持每一个可观察结果不变。如果测试失败了，它就被钉在实现上。

留下能抓住第一种编辑、并且扛得住第二种的测试。其余的改写或删掉。通过公共界面用一个具体输入去驱动代码，并从需求推导期望值。外部服务收到的东西是行为。对内部辅助函数的调用不是。给「这绝不会发生」配一个它确实发生的用例。断言调用方用来分支的错误类型，而不是错误文案。
