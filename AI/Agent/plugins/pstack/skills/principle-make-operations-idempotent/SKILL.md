# 让操作幂等

把每一个改变状态的操作设计成：无论跑多少次、上一次停在哪里，都会收敛到正确状态。

每一步都从已经存在的状态推导，而不是从上一次运行打算做什么推导。读当前状态，把它和目标比较，只应用差额。

一次运行留下的任何东西（锁、临时文件、写了一半的记录、认领的任务），下一次运行都必须能认出它已经过期，依据是在上一次运行任何停点都仍然成立的证据。先写到临时路径，再改名就位。

检验：跑两次会怎样？上一次运行在每一个可能的点崩溃会怎样？如果答案取决于留下了什么，就加一个调和步骤。
