我要的是这个任务更深的版本，不是更大的版本。改写之前，先做四件事：

1. 说出这个领域里顶尖的人在这里会做、而我没开口要的事。
2. 点名他们会从哪一份最原始的材料起步，而不是已经替我消化过的东西。
3. 点名他们会用的具体方法和工具。
4. 说出除了你和我之外，什么能表明结果是对的。

然后把我的 prompt 改写成正好要这些。

改写后的 prompt 要让 agent 把实验能定的选择先做成原型，并根据观察到的结果推荐一个选项。实验定不了的产品或偏好选择，留给我来做。
