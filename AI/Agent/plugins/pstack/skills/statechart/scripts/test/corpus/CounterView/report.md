# CounterView

TLC 到达了 5 个状态、4 步。图中画出 4 个状态、5 条箭头。
约束之外的 1 个状态结束了一条规则的路径，图中包含了它。TLC 会检查约束之外的状态里的规则，但不会从那里继续往下探索。
约束排除的 1 步结束了一条规则的路径，图中包含了这一步。TLC 会在这类步骤之后检查规则，但不会走这一步。

## NotOdd 不成立
最短路径有 1 步：
0. 0
1. Inc: odd

## NotThree 不成立
最短路径有 1 步：
0. 0
1. Jump: odd

## NotFive 不成立
最短路径有 5 步：
0. 0
1. Inc: odd
2. Inc: 2
3. Inc: odd
4. Inc: 4
5. Inc: odd
