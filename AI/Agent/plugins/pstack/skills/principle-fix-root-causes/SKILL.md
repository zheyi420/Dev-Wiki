# 修根因

修故障本身，而不是它露出来的地方。根因是系统第一次做了不该做的事，或者没处理它本该处理的状态。

- 先复现。一直问「为什么」，直到答案是代码里一个错误决定。卡住时就插桩，读真正的状态。
- 问触发症状的那个状态是不是合法的。如果是，就在代码崩掉的地方处理它。如果它本不该存在，在那里加检查只会把 bug 藏起来，所以去找是什么产生了它。守卫、重试、吞掉的错误、钳制的值、丢掉的状态，是藏 bug 的常见办法。
- 修的是这个模式，不只是这一处。找到每一处同样的故障。
- 如果那个决定性的事实要深挖才找得到，就提出一个便宜、一直开着的信号，让它第一眼就能看见。
