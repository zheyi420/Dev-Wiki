Magnet URI scheme 磁力链接

> magnet:?xt=urn:btih:25AA00JC88C89……
>
> xt: exact topic
>
> urn: uniform resource name
>
> btih: BitTorrent Info Hash
>
> 25AA00JC88C89……: 40位16进制字符，文件哈希运算结果值

DHT 网络 Distributed Hash Table 分布式哈希表（一个高宽容度的去中心化网络）

BitTorrent 协议下载

资源由所有人提供给所有人。下载的人越多速度越快。Peer To Peer

弱点：Tracker Server，无人在线，速度为零。

传统下载：

资源由一个人或一个中心服务器提供。
