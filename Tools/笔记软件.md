# 问题

- 几乎所有的类 Notion 软件都是存储在商家服务器上，不太安心，尤其是日记类文档。更担心误删。
- 有许多是可以自己部署在个人服务器上，但或者 markdown 编辑太突兀，或者没有 Notion 编辑便捷美观。

# 解决

目前看了那么多，最好的选择是 https://github.com/zadam/trilium 。可以部署在自己服务器，其他地方连接同步，但无移动端应用。

- trilium 替代 notion。
- Logseq 双链日记类记录（不确定有无需要，先试试吧）
  - [Logseq 双链笔记系列教程](https://www.zhihu.com/column/c_1370057617461526528)
  - https://finncode.cn/logseq/#/page/contents
  - https://sspai.com/search/post/logseq
