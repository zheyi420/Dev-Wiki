# 地图瓦片

瓦片通常有两种形式：栅格和矢量。两者的区别可以理解为：原始地理数据在何时被转换为（理想情况下）最终用户视觉体验良好的形式。

---

# 栅格与矢量

|      | 栅格瓦片                     | 矢量瓦片                          |
| ---- | ------------------------ | ----------------------------- |
| 传输内容 | 预渲染的像素图，如 PNG、JPEG       | 压缩后的矢量几何与属性，如 MVT / PBF       |
| 渲染时机 | **服务端**（或缓存层）完成样式与制图     | **客户端**按样式规则实时绘制              |
| 典型服务 | XYZ、WMTS（栅格）、WMS 瓦片缓存 | Vector Tile Server、XYZ/TMS（.mvt/.pbf）；部分服务端（如 GeoServer GWC）亦可通过 WMTS 输出 MVT |
| 优势   | 客户端轻量，样式固定时表现稳定          | 可动态换样式，缩放更清晰，交互与要素级拾取更好       |
| 代价   | 样式变更需重新切片；超出切片层级放大后会模糊   | 客户端需具备 Canvas / WebGL 渲染能力    |

数据源与各厂商瓦片 URL 见 [Layer-Source](/GIS/Data/Layer-Source.md)。

> 与 [3D-Tiles](/GIS/Data/Data-Spec/3D-Tiles.md) 的区别：3D Tiles 面向三维场景（建筑、点云、倾斜摄影等）的流式加载，本文讨论的是 Web 地图常用的二维栅格 / 矢量切片。
